# 角色（player）合成素材

把你**手动抠好的角色图块**放到这个目录：`ml/player/*.png`。

`synth.py` 会把它们当作 `player` 类，和怪物一起合成到训练数据里（每张合成图必贴 1 个角色，位置/翻转/缩放随机），并自动写好 YOLO 标注。无需改任何代码。

## 抠图要求（两种都支持，任选其一）

1. **透明 PNG（推荐）**：在任意图片编辑器里把角色以外的背景擦成透明，导出带 alpha 通道的 PNG。`synth.py` 会用 alpha 通道当遮罩。
2. **绿幕 PNG**：把背景填成纯绿 `(R=0, G=255, B=0)`，其余保留。和 `monster/` 素材同一套规则。

## 抠图建议

- 从**真实游戏截图**里抠，最贴近部署画面。
- 框**只包住角色身体**（可含头顶名牌，也可不含——保持一致即可）。裁剪时尽量贴边、少留背景。
- 多抠几张不同**朝向/动作/装备**的（10~30 张即可），多样性越高越好。
- 文件名随意，如 `player_01.png`、`fulilian_left.png`。

## 放好素材后

```bash
python ml/synth.py --n 800     # 会自动把 player 加入 data.yaml 并合成
python ml/train.py --epochs 100
```

`data.yaml` 里 `player` 会被追加为**最后一个类别**（索引最大），这样以后增减怪物不会打乱它的编号。
